# Changelog

All notable changes to this plugin are documented here.

## 1.0.0 — 2026-11-11

First public release.

- Draggable, snapping music ball in the Harness Web UI.
- Circular black-and-white default icon; rotating album cover and green progress ring during playback.
- Single-click control bar with seek bar, favorite, previous/play/next, playback modes, vertical volume control, and playlist shortcut.
- Double-click / right-click library view with current track, playlist, favorites, library, and custom collections.
- Local audio import by file selection, folder import, and drag-and-drop.
- IndexedDB persistence for audio, covers, favorites, per-track cover zoom, playlist, collections, and current track.
- Global and per-track cover zoom to trim white borders.
- Optional automatic half-hide with 5/10/30 second delay and playback-only mode.
- Playlist search, drag reordering, arrow reordering, and play-all actions.
- Source-aware library deletion with an optional folder-source delete and a "do not show again" preference.
- First-run guide, settings sections, source badges, and localized English/Chinese UI.
- No network requests, analytics, or cloud sync.
